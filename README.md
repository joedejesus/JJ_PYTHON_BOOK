# JJ_PYTHON_BOOK  
### *Libro interactivo de Python — diseñado para Visual Studio Code*

## 📘 Descripción

**JJ_PYTHON_BOOK** es la primera parte de un libro interactivo para aprender Python de forma práctica,  
modular y progresiva.

✨ No es un PDF ni un libro tradicional.  

👉📝 Es un **entorno de aprendizaje** pensado para usarse directamente en **Visual Studio Code**,  
aunque también puede consultarse desde GitHub para revisar conceptos o resolver dudas rápidas.

✨ El repositorio contiene **21 capítulos**, cada uno en su propia carpeta.  

👉📝 Al descargar el proyecto, obtienes **una sola carpeta con todo el libro**, tal como fue diseñado para VS Code.

✨ No es solo un libro. 

👉📝 También funciona como una **herramienta de consulta diaria**, un pequeño **cuaderno de apuntes vivo** 
que puedes abrir mientras programas para recordar conceptos, copiar ejemplos, revisar sintaxis o aclarar 
dudas al instante. Está pensado para acompañarte en tu día a día como programador.

La filosofía, el origen del proyecto y la narrativa completa se encuentran en el capítulo:

**01_INTRODUCCION/**

## 💡 Por qué Visual Studio Code

VS Code permite:

- ejecutar código al instante  
- editar y experimentar con facilidad  
- convertir cada capítulo en un entorno interactivo  
- aprender de forma moderna y práctica  

Aunque el contenido puede consultarse desde GitHub, la experiencia completa está pensada para VS Code.

---

## 🛠️ Cómo usar este libro

### ✔ 1. Descarga el repositorio completo

Pulsa **Code → Download ZIP** o usa:

```
git clone https://github.com/joedejesus/JJ_PYTHON_BOOK
```

### ✔ 2. Ábrelo en VS Code

Archivo → Abrir carpeta → `JJ_PYTHON_BOOK`

### ✔ 3. Avanza capítulo por capítulo

Cada carpeta es un tema.  
Cada archivo es una explicación o ejemplo.  
La estructura está diseñada para aprender **interactuando con el código**.
